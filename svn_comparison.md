# 1. Почему ветвление в Git «дешёвое», а в SVN «дорогое»?

**Git:** ветка — это просто указатель на коммит. Переключение и слияние происходят **локально**, без сети.

**SVN:** создание ветки дёшево, но `switch` и `merge` требуют **обращения к серверу**, что медленно и неудобно. Поэтому ветки использовали редко.

# 2. Можно ли в SVN коммитить без интернета?

**Нет.** SVN централизован: вся история на сервере, локально — только рабочая копия. `svn commit` без сети невозможен.

# 3. Когда SVN предпочтительнее Git?

- **Огромные бинарные файлы** (GameDev, CAD) — можно выкачивать часть репозитория.
- **Тонкие права доступа** на уровне папок.
- **Пессимистичные блокировки** для файлов, которые нельзя сливать.
- **Строгая линейная нумерация ревизий** (аудит, ISO).
